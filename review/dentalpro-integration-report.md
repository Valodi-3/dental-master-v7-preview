# Dental Atlas 4.1 — DentalPRO branch handoff

## Scope

Работа выполнена в ветке `codex/dental-atlas-4-1-premium` PR #2. `main` и production не изменялись.

## Что подтверждено официальной документацией

Официальная инструкция DentalPRO описывает онлайн-запись через виджет клиники: пациент выбирает филиал, тип/направление приёма, врача, дату и свободное время, после чего подтверждает контактные данные. Для подключения онлайн-записи документация направляет владельца в техническую поддержку DentalPRO. Источник: [официальная документация DentalPRO](https://dental-pro.online/support_new/onlayn-zapis-patsienta-cherez-sayt-kliniki7935/).

Документация подтверждает сам сценарий выбора филиала, но не публикует для этого проекта отдельные токены, ID филиалов или безопасный URL-параметр, который можно было бы подставить самостоятельно.

## Фактическая конфигурация

- В текущем каталоге проекта указан один внешний адрес: `https://dantist-prokshino.ru/online-zapis/`.
- На рабочей странице этого адреса опубликован iframe DentalPRO с подписью филиала Прокшино.
- Прямая проверка iframe в Chromium вернула текст `Онлайн запись на прием · Токен не найден`; запрос виджета `/api/companies` ответил HTTP 404 с ошибкой `Токен не найден`.
- Подтверждённого отдельного токена/ID филиала Испанских кварталов и документированного параметра передачи филиала в доступных материалах нет.

Поэтому существующая ссылка не используется как онлайн-запись Испанских кварталов, а свободные слоты и успешная запись не имитируются.

## Реализовано

1. В модальном окне записи добавлен явный шаг **«1 · Филиал»** с вариантами «Испанские кварталы» и «Прокшино». На странице конкретного филиала вариант выбирается автоматически.
2. Добавлен шаг **«2 · Услуга»**. Если окно открыто из карточки услуги, выбранная позиция и цена сохраняются в контексте модального окна как ориентир; данные не подменяют данные DentalPRO.
3. Каналы вынесены в шаг **«3 · Способ записи»**.
4. Для Испанских кварталов онлайн-ссылка не выдаётся за рабочую: карточка явно сообщает, что подтверждённого DentalPRO-канала нет, и оставляет телефон/WhatsApp/Telegram.
5. Для Прокшино сохраняется официальный переход на существующую страницу, но рядом отображается предупреждение о фактическом ответе `Токен не найден`. Слоты не показываются локально.
6. Переключение филиала не меняет цены, врачей, контакты, расписания или базу DentalPRO.

## Что осталось неподтверждённым

- Рабочий токен/URL DentalPRO для Испанских кварталов.
- Исправленный токен/активный виджет Прокшино: текущий внешний адрес отвечает `Токен не найден`.
- ID филиалов и документированный способ передавать выбранную услугу/врача в URL.
- Реальный выбор слота и отправка записи: не выполнялись, чтобы не создавать запись реальному пациенту.

Для окончательного включения онлайн-записи обоих филиалов нужен валидный общий или отдельные токены от DentalPRO/владельца клиники. До этого интерфейс безопасно направляет Испанские кварталы в подтверждённые каналы связи и не обещает несуществующие слоты.
