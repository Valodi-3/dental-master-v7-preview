## Принципы, применимые к Dental Atlas

1. На мобильном сначала показывать один выразительный кадр, затем компактный текстовый блок; Maison, 390 px: фото 250 px над текстом 364 px.
2. На десктопе допустим полноширинный hero-фон с контролируемым затемнением и коротким текстом в одной зоне; Maison, 1440 px: 484.5 px hero и H1 64 px.
3. Одна главная запись должна быть визуально приоритетной в шапке; Maison и Grand Street, 1440 px: отдельные Book / Book Online размером 173–190×49–75 px.
4. На мобильном навигацию сворачивать в hamburger, чтобы не уменьшать размер интерактивных пунктов; оба доступных референса, 390 px.
5. Абстрактная графика может быть самостоятельным hero-мотивом, но её нельзя выдавать за фотографию клиники; Grand Street, обе ширины: 0 клинических фото в первом экране.
6. Отступы между смысловыми блоками должны быть заметными и измеримыми: Grand Street, 390 px — 62–80 px; 1440 px — 80–130 px.
7. Cookie-consent не должен быть принят за часть визуальной композиции; Maison снят после штатного `Deny`, а состояние баннера зафиксировано отдельным первоначальным запуском.

## Что не удалось или вызывает сомнения

- HelloTend (`https://www.hellotend.com/site/home`) отдаёт HTTP 403 Cloudflare в Playwright. Его настоящий hero, навигация и CTA нельзя добросовестно измерить по полученной странице. Для полного сравнения нужен скриншот/доступ из обычного браузера, который проходит проверку сайта.
- У Maison часть hero-изображения задана CSS `background-image`, поэтому количество фото определено по визуальному кадру и computed style, а не по `img`-элементам.
- Запись референсных сайтов не имитировалась и не отправлялась; проверялись только видимые ссылки и кнопки.

Этап C не начинался. Следующий шаг — только после проверки этого отчёта.
