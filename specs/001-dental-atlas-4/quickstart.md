# Quickstart: Dental Atlas 4.0 Preview

From the repository root:

```powershell
python -m http.server 4174
```

Open:

- `http://127.0.0.1:4174/atlas-v4/`
- `http://127.0.0.1:4174/atlas-v4/prokshino/`
- `http://127.0.0.1:4174/atlas-v4/ispanskie/`

Review the service search, category pages, doctor pages, gallery, contacts and booking handoff at the required widths. The preview does not create real appointments and must not be treated as a production deployment.
