# TWO_STRUCTURAL_SOLUTIONS.md
## Сравнение двух принципиально разных структурных решений DENTAL ATLAS

---

### Архитектурная дилемма

Традиционный сайт клиники строится по принципу вертикального свитка («длинный лендинг»).  
Для концепции **DENTAL ATLAS** разработаны два альтернативных, принципиально разных структурных подхода, не имеющих ничего общего с шаблонным лендингом.

---

### РЕШЕНИЕ 1: «Интерактивный Атлас-Консоль» (The Clinical Canvas)
*Статус: Выбрано в качестве основы для интерактивного прототипа*

```
+-----------------------------------------------------------------------------------+
|  [Logo] ДАНТИСТЪ  |  [● Испанские кварталы | ○ Прокшино]  |  [Услуги|Врачи|Запись]  |  +7(904)... |
+-----------------------------------------------------------------------------------+
|  КОНТЕКСТ-ЛЕНТА: Главная > Услуги > Имплантация > Straumann              [← Назад]|
+-----------------------------------------+-----------------------------------------+
| РЕЕСТР НАВИГАЦИИ (40% ширины)           | ДИНАМИЧЕСКАЯ СЦЕНА ОБЪЕКТА (60% ширины) |
| [ Поиск процедуры...                ]   | +-------------------------------------+ |
|                                         | | [Аутентичное фото кабинета/оптики]  | |
| [◎ Диагностика           ]              | +-------------------------------------+ |
| [◎ Лечение зубов         ]              | Установка имплантата Straumann          |
| [● Имплантация зубов    ]              | Официальная цена филиала: 66 000 ₽      |
|    - Osstem (Корея)         36 000 ₽    | --------------------------------------- |
|    - Straumann (Швейцария)  66 000 ₽ <  | Клиническое описание протокола...       |
|    - Одномоментная импл.    45 000 ₽    | Врач: Даниелян А.Я. (хирург, 25 лет)    |
| [◎ Протезирование        ]              | +-------------------------------------+ |
| [◎ Ортодонтия            ]              | | [ЗАПИСАТЬСЯ НА ПРИЁМ] [ДРУГИЕ ВРАЧИ]| |
| [◎ Профгигиена           ]              | +-------------------------------------+ |
+-----------------------------------------+-----------------------------------------+
```

#### Ключевые свойства:
1. **Единая рабочая консоль:** Пользователь управляет навигацией, видит список и результат выбора в одном скоординированном поле зрения.
2. **Нулевой лишний скролл:** Экран десктопа укладывается в видимый вьюпорт (100vh / compact flow), мобильный экран компонуется в строгую логическую последовательность с горизонтальными чипами.
3. **Мгновенный контекстный переход:** Клик на врача в карточке услуги мгновенно переключает правую сцену в режим досье доктора, не сбрасывая состояние каталога.

#### Преимущества:
- Самый быстрый путь от входа на сайт до понимания цены и записи ($\le 3$ кликов);
- Не создаёт ощущения громоздкости и усталости от чтения длинных маркетинговых простыней;
- Идеальная поддержка глубоких ссылок (`?view=services&cat=implants&id=straumann`) и истории браузера.

#### Недостатки и риски:
- Требует строгой дисциплины в длине медицинских текстов: текст карточки должен быть ёмким и информативным, без пространных «водянистых» абзацев.

### РЕШЕНИЕ 2: «Архитектурное Досье» (Split Studio / Architectural Dossier)

```
+-----------------------------------------------------------------------------------+
|  [Logo] ДАНТИСТЪ  |  [Филиал: Испанские кв.]  |  [Меню]                |  [Записаться]   |
+-------------------------------------------------+---------------------------------+
| ЛЕВАЯ НЕЗАВИСИМАЯ СКРОЛЛ-ЛЕНТА                  | ПРАВАЯ ЗАФИКСИРОВАННАЯ ВИТРИНА  |
| (Скроллируемый каталог карточек-досье)          | (Sticky Showcase)               |
|                                                 |                                 |
| [01] ДИАГНОСТИКА                                | +-----------------------------+ |
|      Консультация с планом ...    2 500 ₽       | |                             | |
|      КТ челюсти (3D)              3 500 ₽       | | Крупное интерьерное фото    | |
|                                                 | | выбранного филиала          | |
| [02] ИМПЛАНТАЦИЯ                                | | с немецкой оптикой          | |
|      Osstem                       36 000 ₽      | |                             | |
|      Straumann                    66 000 ₽ [>]  | +-----------------------------+ |
|                                                 | Стоматология «ДантистЪ»         |
| [03] ВРАЧИ КЛИНИКИ                              | Испанские кварталы              |
|      Даниелян Арам Яковлевич (25 лет)           | ул. Магеллана, 5                |
|      Наджафов Азер Этибарович (10 лет)          | Ежедневно 09:00 - 21:00         |
|                                                 |                                 |
| (При клике на [>] справа выезжает шторка досье) | [ПОЗВОНИТЬ В КЛИНИКУ]           |
+-------------------------------------------------+---------------------------------+
```

#### Ключевые свойства:
1. **Журнальная эстетика:** Интерфейс напоминает архитектурное портфолио или монографию премиум-клиники.
2. **Асимметричный сплит:** Левая часть содержит длинный типографический свиток сущностей с большими цифровыми индексами; правая часть удерживает фокус на атмосфере клиники и контактах.
3. **Выдвижные панели (Drawers):** Подробности открываются в накладывающейся боковой панели или мобильной шторке.

#### Преимущества:
- Очень сильный визуальный имиджевый образ, максимально далёкий от любых типовых стоматологических сайтов;
- Позволяет размещать развёрнутые сертификаты, биографии и описания клинических протоколов без ограничений по высоте.

#### Недостатки и риски:
- Независимый скролл половины экрана (Nested Scrolling) на трекпадах и колесе мыши часто вызывает ошибки взаимодействия у пользователей старшего возраста;
- На мобильных устройствах шторки создают глубокую вложенность (нужно закрывать модалку, чтобы вернуться к скроллу списка);
- Выше сложность реализации доступности (`aria-expanded`, ловушки фокуса).

---

### Вывод рабочей группы
Для создания прототипа в качестве основного выбрано **Решение 1 («Интерактивный Атлас-Консоль»)** как обеспечивающее лучший баланс инженерной надёжности, скорости загрузки, удобства на смартфонах и понятности для реального пациента.
