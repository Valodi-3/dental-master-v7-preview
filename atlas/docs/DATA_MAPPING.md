#### 2.2. Направления и процедуры (`categories` & `procedures`)
Из 254 позиций `services_master.json` для витрины цифрового атласа сформированы 6 базовых направлений:
1. `diagnostics` — «Диагностика и консультации» (прицельные снимки, КЛКТ, консультация главного врача);
2. `treatment` — «Лечение зубов» (лечение кариеса, эстетическая реставрация, эндодонтия под микроскопом Zeiss);
3. `implants` — «Имплантация» (системы Osstem, Straumann, одномоментная имплантация);
4. `prosthetics` — «Протезирование» (керамические коронки E-max, цирконий, виниры);
5. `orthodontics` — «Ортодонтия и прикус» (элайнеры, металлические и керамические брекет-системы);
6. `hygiene` — «Профгигиена и профилактика» (комплексная чистка Air-Flow, ультразвук, фторирование).

**Маппинг процедуры:**
```typescript

  id: string; // Уникальный ключ (напр. 'straumann')
  catId: string; // Категория (напр. 'implants')
  name: string; // Точное наименование из прайса (напр. 'Установка имплантата Straumann (Швейцария)')
  tag: string; // Клиническая группа (напр. 'Премиум-класс')
  desc: string; // Краткое клиническое описание сути процедуры
  prices: {
    ispanskie: string; // Подтверждённая цена для филиала Испанские кварталы
    prokshino: string; // Подтверждённая цена для филиала Прокшино
  };
  doctorSlugs: string[]; // Слаги врачей из doctors.json, выполняющих процедуру
  images: {
    ispanskie: string; // Аутентичное фото кабинета Испанских кварталов
    prokshino: string; // Аутентичное фото кабинета Прокшино
  };
}
```

### 3. Запрещённые фиктивные данные (Anti-Hallucination Checklist)

- ❌ **Длительности процедур:** Убраны все выдуманные «15–30 мин», «40 мин», «60–90 мин». Время стоматологического приёма индивидуально и зависит от анатомии корней и протокола.
- ❌ **Свободные слоты:** Запрещены псевдо-календари с фиктивными ячейками записи.
- ❌ **Медицинские гарантии:** Запрещены формулировки «пожизненная гарантия на всё» или «100% приживаемость».
- ❌ **Поддельные отзывы:** Запрещены любые фиктивные цитаты «пациентов».
- ❌ **Перекрёстные фото:** Фото филиала Прокшино не должны выдаваться за фото Испанских кварталов.
