# ART_DIRECTION_PROPOSAL.md
## DENTAL ATLAS — Концепция художественного руководства (GATE 3: Art Direction)

На этапе **GATE 3** для принятой архитектурной консоли «The Clinical Canvas» разработаны два принципиально разных художественных решения. Они различаются не просто цветом кнопок, а целостной философией пространства, типографической культурой, характером светотени, масштабом и эмоциональным восприятием.

---

### 1. Сравнительная матрица двух художественных решений

| Параметр | Направление 1: «Архитектурное Редакционное» (Architectural Editorial) | Направление 2: «Высокоточная Клиническая» (Modern High-Tech Clinical) |
| :--- | :--- | :--- |
| **Основной образ** | Премиальное архитектурное издательство, галерея света, итальянский травертин | Швейцарская клиника точной микрохирургии, оптика Carl Zeiss, титановая прецизионность |
| **Эмоция посетителя** | Спокойствие, достоинство, эстетическое доверие, комфорт семейной клиники | Технологическое превосходство, абсолютная стерильность, бескомпромиссная точность |
| **Цветовая палитра** | Тёплый известняк (`#fbf9f5`), мраморный фарфор (`#ffffff`), умбристый графит (`#1c1917`), античная бронза (`#b48c48`) | Глубокий минеральный графит (`#0c1512`), изумрудно-хвойный шалфей (`#0d382b`), Carl Zeiss Green (`#10b981`), холодная платина (`#e2e8f0`) |
| **Типографика** | **Cormorant Garamond** (антиква, serif) + **Plus Jakarta Sans** (текст) | **Manrope** (швейцарский нео-гротеск) + **JetBrains Mono** (моноширинный прайс) |
| **Геометрия и границы** | Мягкие деликатные радиусы (12–16 px), тончайшие минеральные границы `1px solid #e7e2d8`, воздушные тени | Строгие технологичные фаски (6–8 px), чёткие лазерные микро-бордеры с акцентным свечением (glow) |
| **Подача фотографий** | Тёплая естественная тональность интерьеров, естественный дневной свет, рамки с отступами passe-partout | Холодная контрастная оптика, макро-детали инструментов, акцент на микроскопах Zeiss и имплантатах Straumann |
| **Идеально для филиала** | **Испанские кварталы** (флагманская семейная стоматология в престижном жилом комплексе) | **Прокшино** (высокотехнологичный центр сложной имплантации и микроскопии) |

---

### 2. Детальная спецификация Направления 1: «Архитектурное Редакционное»

#### 2.1. Цветовая система
* `--atlas-bg: #fbf9f5;` — тёплый оттенок травертина и выбеленного холста;
* `--atlas-surface: #ffffff;` — чистый фарфоровый тон для рабочих поверхностей;
* `--atlas-surface-subtle: #f5f1eb;` — мягкая подложка навигационных панелей;
* `--atlas-border: #e8e2d8;` — деликатная граница, имитирующая архитектурные фаски;
* `--atlas-ink-loud: #1c1917;` — глубокий масляно-черный графит для заголовков;
* `--atlas-ink-text: #44403c;` — мягкий темный камень для комфортного длительного чтения;
* `--atlas-ink-muted: #78716c;` — нейтральный серый шёлк для вспомогательных меток;
* `--atlas-accent: #b48c48;` — тёплый античный шампань/бронза;
* `--atlas-accent-bg: #faf6ee;` — деликатная подсветка выбранных сущностей.

#### 2.2. Типографический строй
* **Заголовки первого уровня и названий процедур:**  
  `font-family: 'Cormorant Garamond', Georgia, serif;`  
  `font-weight: 500; font-size: clamp(1.6rem, 2.6vw, 2.2rem); line-height: 1.2;`  
  Применение курсивных выделений `<em>` для ключевых акцентов («*Имплантация Straumann*»).
* **Интерфейс, кнопки, навигация:**  
  `font-family: 'Plus Jakarta Sans', -apple-system, sans-serif;`  
  `font-weight: 600; letter-spacing: 0.02em;`

#### 2.3. Микро-взаимодействия и анимация
* Время отклика: `280ms cubic-bezier(0.2, 0.8, 0.2, 1)`;
* Мягкий подъём карточек (`transform: translateY(-2px)`) с тенью `0 12px 30px rgba(70, 50, 30, 0.06)`;
* Плавное проявление фотографий кабинетов через деликатное растворение (`cross-fade`).

---

### 3. Детальная спецификация Направления 2: «Высокоточная Клиническая»

#### 3.1. Цветовая система
* `--atlas-bg: #0b1411;` — глубокий минеральный графит (ночной швейцарский холст);
* `--atlas-surface: #11201b;` — матовая стеклокерамическая поверхность;
* `--atlas-surface-subtle: #0d1a15;` — теневой уровень глубины навигатора;
* `--atlas-border: #1e362d;` — точная лазерная граница;
* `--atlas-border-glow: rgba(52, 211, 153, 0.35);` — активное микро-свечение при наведении;
* `--atlas-ink-loud: #ffffff;` — чистый кристальный белый цвет максимального контраста;
* `--atlas-ink-text: #cbd5e1;` — светлая платина для параметров и цен;
* `--atlas-ink-muted: #64748b;` — технический приглушённый шалфей;
* `--atlas-accent: #10b981;` — чистый оптический изумруд Carl Zeiss;
* `--atlas-accent-glow: rgba(16, 185, 129, 0.2);` — ореол прецизионного оборудования.

#### 3.2. Типографический строй
* **Заголовки и названия процедур:**  
  `font-family: 'Manrope', -apple-system, sans-serif;`  
  `font-weight: 800; letter-spacing: -0.03em; line-height: 1.18; text-transform: none;`
* **Официальные цены прейскуранта:**  
  `font-family: ui-monospace, SFMono-Regular, "JetBrains Mono", monospace;`  
  `font-weight: 800; letter-spacing: -0.02em;`
* **Служебные бейджи и индексы:**  
  Инженерная маркировка (`ZEISS-OPTICS // STRAUMANN-SLActive`).

#### 3.3. Микро-взаимодействия и анимация
* Время отклика: `180ms cubic-bezier(0.4, 0, 0.2, 1)` — мгновенный тактильный щелчок;
* Неоновое микро-свечение контура при фокусе (`box-shadow: 0 0 0 1px #10b981, 0 0 20px rgba(16, 185, 129, 0.15)`);
* Механическая точность смены процедур без расфокусировки внимания.

---

### 4. Интерактивное переключение в живом прототипе

В верхней панели интерфейса реализован переключатель художественного направления:  
`[🏛 Редакционное направление] | [🔬 Клиническое направление]`

Параметр синхронизируется в URL:
- `?theme=editorial` — включает светлую архитектурную редакционную систему;
- `?theme=clinical` — включает контрастную высокоточную клиническую систему.

Пользователь и заказчик могут оценить оба решения на одном и том же наборе реальных данных, на компьютерах и смартфонах без перезагрузки страницы.
